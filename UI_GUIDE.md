# UI Screenshots and Design Guide

## Application Overview

Post Delivery is a beautiful Flutter parcel delivery application inspired by Flash Express design language.

## Color Scheme

```
Primary Orange: #FF6B00
Secondary Yellow: #FFB800
Background: #FFFFFF
Text Primary: #000000
Text Secondary: #666666
Success Green: #4CAF50
```

## UI Components

### Cards with Shadow
- Elevation: 2-4
- Border Radius: 12-16px
- Padding: 16-20px

### Buttons
- Primary: Orange (#FF6B00)
- Border Radius: 12px
- Padding: 16px vertical, 32px horizontal

### Gradients
- Orange to Yellow: #FF6B00 → #FFB800
- Direction: Top-Left to Bottom-Right

### Status Badges
- Border Radius: 12px
- Padding: 6px 12px
- Colors:
  - Pending: Orange (#FF6B00)
  - Success: Green (#4CAF50)
  - Info: Blue (#2196F3)

### Timeline
- Connector: 2px solid line
- Node: 24px circle
- Active: Orange (#FF6B00)
- Inactive: Grey (#E0E0E0)

## Spacing System

- XXS: 4px
- XS: 8px
- S: 12px
- M: 16px
- L: 20px
- XL: 24px
- XXL: 32px

## Typography

- Display: 28px, Bold
- Title: 20px, Bold
- Heading: 18px, Bold
- Body: 16px, Regular
- Caption: 14px, Regular
- Small: 12px, Regular

## Icons

- Size: 24-32px (standard)
- Size: 16-20px (small)
- Size: 64-100px (large/empty state)
- Color: Matches context (primary/grey)
