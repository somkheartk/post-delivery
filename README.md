# Post Delivery - แอปพลิเคชันส่งพัสดุ

แอปพลิเคชัน Flutter สำหรับจองส่งพัสดุ รับพัสดุ และติดตามพัสดุ ที่ออกแบบมาให้สวยงามและใช้งานง่าย ได้รับแรงบัลดาลใจจาก Flash Express

## ✨ คุณสมบัติหลัก

### 📦 จองส่งพัสดุ
- กรอกข้อมูลผู้ส่งและผู้รับ
- เลือกขนาดพัสดุ (S, M, L, XL)
- ระบุน้ำหนักพัสดุ
- คำนวณค่าส่งอัตโนมัติ
- ได้รับหมายเลขติดตามทันที

### 🔍 ติดตามพัสดุ
- ค้นหาพัสดุด้วยหมายเลขติดตาม
- ดูสถานะการจัดส่งแบบเรียลไทม์
- Timeline แสดงประวัติการจัดส่ง
- ประมาณการเวลาถึงปลายทาง

### 📥 รับพัสดุ
- ดูรายการพัสดุทั้งหมด
- กรองพัสดุตามสถานะ (พร้อมรับ/รับแล้ว)
- รายละเอียดพัสดุแบบครบถ้วน
- ยืนยันการรับพัสดุ
- รองรับการสแกน QR Code

## 🎨 การออกแบบ

- UI/UX ที่สวยงามและทันสมัย
- สีส้ม (#FF6B00) เป็นสีหลัก ได้รับแรงบัลดาลใจจาก Flash Express
- Gradient และ Shadow ที่ดูมีมิติ
- Animation และ Transition ที่ลื่นไหล
- รองรับภาษาไทย

## 🚀 การติดตั้งและรัน

1. ติดตั้ง Flutter SDK
```bash
flutter --version
```

2. ติดตั้ง dependencies
```bash
flutter pub get
```

3. รันแอปพลิเคชัน
```bash
flutter run
```

## 📱 หน้าจอหลัก

1. **หน้าหลัก (Home)** - แสดงบริการทั้งหมดและข้อมูลเพิ่มเติม
2. **ติดตามพัสดุ (Tracking)** - ค้นหาและติดตามสถานะพัสดุ
3. **รับพัสดุ (Receiving)** - จัดการและรับพัสดุ

## 🛠 เทคโนโลยีที่ใช้

- **Flutter** - Framework หลักสำหรับพัฒนาแอป
- **Material Design** - ระบบออกแบบจาก Google
- **Google Fonts** - ฟอนต์ Inter
- **intl** - จัดการรูปแบบวันที่และเวลา

## 📦 โครงสร้างโปรเจกต์

```
lib/
├── main.dart                    # จุดเริ่มต้นของแอป
└── screens/
    ├── home_screen.dart         # หน้าหลักและแถบนำทาง
    ├── booking_screen.dart      # หน้าจองส่งพัสดุ
    ├── tracking_screen.dart     # หน้าติดตามพัสดุ
    └── receiving_screen.dart    # หน้ารับพัสดุ
```

- ✅ รับพัสดุและจัดการรายการ
